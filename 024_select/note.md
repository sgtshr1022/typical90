# 024 Select +／- One（★2）

問題URL: https://atcoder.jp/contests/typical90/tasks/typical90_x

## 問題の要点
- 数列AをBに一致させたい
- 1回の操作で、Aのどれか1要素を+1または-1できる
- ちょうどK回操作して、A=Bにできるかを判定する(YesかNoか)

## 使ったアルゴリズム・考え方
- 各iについて、AiをBiに合わせるのに最低限必要な操作回数は |Ai - Bi| で、これは一方向(増やすだけ/減らすだけ)の最短手数
- 全体の最小操作回数は diff = Σ|Ai - Bi|
- K回ちょうどで達成する条件は2つ
  1. K >= diff(最低限の回数を下回っていたら不可能)
  2. (K - diff) が偶数であること(余った回数は「+1してから-1」のように2回1組で無駄打ちすれば帳尻が合うが、奇数回余ると帳尻が合わない)
- この2条件を満たせばYes、それ以外はNo

## つまずいた点
- 特になし。パリティ(偶奇)を使う典型パターンとして見た瞬間に気づけた

## 学び・次に活かすこと
- 「最短手数」と「ちょうどK回」を分けて考え、余った回数は2で割り切れるかで帳尻合わせが可能かを判定する、というパターンは典型90問023番のキーワード「パリティを考える」と同系統
- 同じ思考の型が使える問題として、ABC086-C(Traveling)、AGC002-A(Range Product)、AGC020-A(Move and Win)などがある。今後類題に出会った時のために覚えておく
