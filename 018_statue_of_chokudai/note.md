# 018 Statue of Chokudai (★3)

問題URL: https://atcoder.jp/contests/typical90/tasks/typical90_r

## 問題の要点
- 直径 L の観覧車が周期 T 分で一定速度で回転している。中心は (0, 0, L/2)、時刻 0 でゴンドラは最下点 (0, 0, 0) にいる。
- 地面上の点 (X, Y, 0) に像がある。
- Q 個の時刻 E_i について、ゴンドラから像を見たときの **俯角（度数法）** を出力する。許容誤差は 1e-7 程度。

## 使ったアルゴリズム・考え方
- 各時刻でのゴンドラ座標を三角関数で求める。回転角を θ = 2π·e / T とすると
  - x = 0
  - y = -(L/2)·sin θ
  - z = (L/2)·(1 − cos θ)
- 俯角は「水平面と、ゴンドラから像への視線の成す角」なので、
  - 水平距離 r = hypot(X − x, Y − y)
  - 高さの差 = z（像は地面 z = 0 にある）
  - 俯角 = atan2(z, r)
- 最後にラジアンを度に変換（× 180 / π）。
- 各クエリ O(1)、全体で O(Q)。

## つまずいた点
- **俯角の定義**：水平線から下向きに測った視線の角度であり、鉛直方向からの角度ではない。「高さ / 水平距離」の arctan になる。
- 回転方向（y 座標の符号）の確認。問題の図の向きに合わせて y = −(L/2)·sin θ とした。
- atan2 の戻り値はラジアンなので度への変換を忘れないこと。
- 出力精度：`fixed << setprecision(10)` を付ける。

## 学び・次に活かすこと
- 俯角・仰角は「水平方向との成す角」。垂直成分と水平成分に分けて `atan2(垂直, 水平)` で求めるのが定石。
- `atan2` は `atan(a/b)` と違って分母 0 や象限を気にしなくてよいので、角度計算では基本こちらを使う。
- 3 次元の距離は `hypot` を使うと簡潔（C++17 以降は 3 引数版の `hypot(x, y, z)` もある）。
- 円運動は「中心 + 半径 × (cos, sin)」で表し、初期位置と回転方向に合わせて符号・位相を調整する。
