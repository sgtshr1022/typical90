# 016 Minimum Coins (★3)

問題URL: https://atcoder.jp/contests/typical90/tasks/typical90_p

## 問題の要点
- 額面 A, B, C 円のコインを使って、合計ちょうど N 円を支払う
- 使うコインの枚数の合計の最小値を求める
- 各コインは 9999 枚以下で答えが作れることが保証されている

## 使ったアルゴリズム・考え方
- 全探索（2重ループ + 残りを計算で決定）
- A の枚数 i と B の枚数 j を 0〜9999 で全探索
- 残り `u = N - (i*A + j*B)` が 0 以上かつ C で割り切れるなら `k = u / C`
- `i + j + k` の最小値を chmin で更新
- 計算量は O(10000^2) = 10^8 程度

## つまずいた点
- 特になし

## 学び・次に活かすこと
- 未知数が3つでも、2つを全探索すれば残り1つは計算で一意に決まる、という典型パターン
- 「割り切れるか」「負にならないか」の2つの枝刈り条件を忘れない
- 全探索の範囲は制約文の保証（9999枚以下）から決める
