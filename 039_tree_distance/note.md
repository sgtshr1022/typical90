# 039 Tree Distance (★5)

問題URL: https://atcoder.jp/contests/typical90/tasks/typical90_am

## 問題の要点
- N 頂点の木で、全ての頂点ペア (i, j)（i < j）について距離 dist(i, j) を求め、その総和を出力する。
- N は最大 10^5 程度で、ペアを全部調べる O(N^2) は間に合わない。

## 使ったアルゴリズム・考え方
- 主客転倒：「ペアごとに距離を足す」のではなく、「各辺が何組のペアの経路で使われるか」を数えて足す。
- 辺を切ると、木は「子の部分木（sz[c] 頂点）」と「それ以外（N − sz[c] 頂点）」に分かれる。
  その辺を通るペアは、両側から1頂点ずつ選ぶ組なので sz[c] × (N − sz[c]) 組。
- 答え = Σ（全ての辺）sz[c] × (N − sz[c])。
- 部分木サイズは BFS 順を逆から見て、子の値を親に足して求める（再帰なし）。
- 辺 (a, b) のうち子の方は、par を使って判定し、swap で a に揃える。
- 計算量 O(N)。答えは最大で約 N^3 / 4 なので long long。

## 学び・次に活かすこと
- 「全ペアの和」は、各要素（ここでは辺）の寄与に分解して数える（主客転倒）と速くなる。
- 木の辺を切る問題では「子の部分木とそれ以外」に言い換える。ABC187 E や昨日の問題と同じ視点。
- BFS 順を1本作れば、逆順で「子 → 親へ集める」処理を再帰なしで書ける。
