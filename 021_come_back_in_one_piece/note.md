021 Come Back in One Piece (★5)

問題URL: https://atcoder.jp/contests/typical90/tasks/typical90_u

問題の要点
N 頂点 M 辺の有向グラフが与えられる。
頂点 x から y へも、y から x へも到達できるペア (x, y)（x < y）の個数を求める。
「互いに行き来できる」＝同じ強連結成分（SCC）に属する、と言い換えられる。
使ったアルゴリズム・考え方
強連結成分分解（SCC）：ACL の scc_graph を使用（計算量 O(N + M)）。
各 SCC のサイズを k とすると、その中から 2 頂点を選ぶ組み合わせは kC2 = k(k−1)/2 通り。
全 SCC について kC2 を足し合わせたものが答え。
異なる SCC 間は片方向にしか到達できないので、カウントに含めなくてよい。

つまずいた点
特になし（SCC を使ったら問題なく AC）。
注意点として、k(k−1)/2 は N = 10^5 程度で int をオーバーフローしうるため、long long で計算した。
細かい点：auto scc_graph = graph.scc(); は ACL の型名 scc_graph と同じ名前の変数になっているので、groups などの別名にした方が安全。

学び・次に活かすこと
「有向グラフで互いに到達可能」というキーワードを見たら SCC を疑う。
SCC 分解後は「成分ごとのサイズで数え上げる」「縮約して DAG 上で DP する」などの典型につなげられる。
ACL の scc_graph::scc() はトポロジカル順に並んだ成分リストを返すので、DAG 上の DP にもそのまま使える。

参考にした解説
なし（自力 AC）
