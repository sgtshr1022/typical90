# 014 We Used to Sing a Song Together（★3）

問題URL: https://atcoder.jp/contests/typical90/tasks/typical90_n

## 問題の要点
- N人の生徒とN個の学校があり、生徒iの現在地A_i、学校iの位置B_iが与えられる
- 生徒と学校を1対1で対応させ、各生徒が自分の対応する学校まで移動する距離の合計を最小化する
- 移動距離の合計の最小値を求める

## 使ったアルゴリズム・考え方
- 生徒と学校をそれぞれソートして、順番通りに対応させるのが最適という貪欲法
- 証明の直感: もし対応が入れ替わっている(交差している)ペアがあれば、その対応を元に戻しても合計距離は増えない(むしろ減るか変わらない)。つまり「ソートして前から順に対応させる」形が最適になる
- 実装は非常にシンプルで、AとBをそれぞれソートし、同じインデックス同士の差の絶対値を全部足すだけ

## つまずいた点
- 特になし。ソート+貪欲の典型パターンとしてすぐに気づけた

## 学び・次に活かすこと
- 「2つの集合を1対1で対応させて、コストの合計を最小化する」タイプの問題は、両方をソートして同じ順位同士を対応させるのが最適、というのは頻出パターン
- 直感だけで済ませず、「交差している対応を元に戻しても悪化しない」という交換論法(exchange argument)を頭の中で確認する癖をつけると、初見の類似問題でも安心して貪欲法を選べる
- 類題として、ABC091-C(2D Plane 2N Points)、ABC131-D(Megalomania)などが挙げられる
