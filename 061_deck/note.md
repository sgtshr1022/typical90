# 061 Deck (★2)

問題URL: https://atcoder.jp/contests/typical90/tasks/typical90_bi

## 問題の要点
- 空のカードの山（デッキ）に対して Q 個のクエリを順に処理する
- クエリ1 `1 x`: 山の一番上にカード x を置く
- クエリ2 `2 x`: 山の一番下にカード x を置く
- クエリ3 `3 x`: 山の上から x 番目のカードの数字を出力する
- Q が大きいので、各操作を O(1) で処理する必要がある

## 使ったアルゴリズム・考え方
- `deque<ll>` をそのまま使うだけ
- 一番上に置く → `push_front`
- 一番下に置く → `push_back`
- 上から x 番目 → 0-indexed に直して `dq[x - 1]`
- deque は先頭/末尾への挿入も、添字アクセスもどちらも O(1)

## つまずいた点
- 特になし
- 強いて言えば、x が 1-indexed なので `x--` して添字にする点

## 学び・次に活かすこと
- 「両端に追加 + ランダムアクセス」が同時に必要なら deque 一択
  - vector: 先頭挿入が O(N) でダメ
  - list: 挿入は O(1) だが x 番目アクセスが O(N) でダメ
- クエリ数が多い問題では出力に `endl`（毎回 flush）ではなく `"\n"` を使うと速い
- データ構造の選択だけで解ける問題は、まず「必要な操作の計算量」を列挙して当てはめる
